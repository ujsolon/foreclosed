# Local API Server Guide

Run the API locally with a real HTTP server before deploying to AWS.

## Quick Start

### 1. Install Dependencies

```powershell
cd backend/api
pip install -r requirements.txt
```

This installs:
- `boto3` - AWS SDK
- `fastapi` - Web framework
- `uvicorn` - ASGI server

### 2. Start the Server

```powershell
python local_server.py
```

You should see:
```
🚀 Starting Foreclosed Property API Local Server
============================================================

📍 Server will be available at:
   http://localhost:8000

📚 API Documentation (auto-generated by FastAPI):
   http://localhost:8000/docs

🔗 Example Endpoints:
   http://localhost:8000/properties
   http://localhost:8000/properties?city=ROXAS&limit=10
   ...
```

### 3. Test the API

Open your browser or use curl:

```powershell
# List all properties
curl http://localhost:8000/properties

# Filter by city
curl http://localhost:8000/properties?city=ROXAS

# Get specific property
curl http://localhost:8000/properties/pagibig_858202309280002

# Get statistics
curl http://localhost:8000/properties/stats
```

## How It Works

```
Browser/Postman/curl
    ↓ HTTP Request
local_server.py (FastAPI)
    ↓ Converts to Lambda event
lambda_function.py
    ↓ Routes request
main.py (API logic)
    ↓ Queries
AWS DynamoDB (real data)
    ↓ Returns data
Browser (JSON response)
```

The local server:
1. ✅ Receives HTTP requests (like a real API)
2. ✅ Converts them to Lambda event format
3. ✅ Calls your existing Lambda handler
4. ✅ Returns the response as HTTP
5. ✅ Connects to real AWS DynamoDB

## Troubleshooting

### Port Already in Use
```
Error: [Errno 10048] error while attempting to bind on address ('0.0.0.0', 8000)
```

**Solution**: Change the port in `local_server.py`:
```python
uvicorn.run(app, host="0.0.0.0", port=8001)  # Use 8001 instead
```

### Module Not Found
```
ModuleNotFoundError: No module named 'fastapi'
```

**Solution**: Install dependencies:
```powershell
pip install -r requirements.txt
```

### AWS Credentials Error
```
UnrecognizedClientException: The security token included in the request is invalid
```

**Solution**: Configure AWS credentials:
```powershell
aws configure
```

### No Data Returned
```json
{"items": [], "count": 0}
```

**Solution**: Load data into DynamoDB:
```powershell
cd ../loader
python loader.py
```
